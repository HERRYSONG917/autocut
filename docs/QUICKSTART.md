# Autocut 新手使用指南

安装并选中 Autocut 后，发 **「开始」** 即可。你也可以说「怎么做」或「我想开始剪辑」。在没有选择技能的新对话里，用「使用 $autocut 开始」明确指定。手边没有素材就选「模拟」。

先看 [七步流程图](../skills/autocut/assets/guide/flow.png)，或打开 [三页图文手册](../skills/autocut/assets/guide/quickstart.pdf)。

适合：1–2分钟人物口播、商业IP、产品广告、工厂宣传、人物＋电脑演示、活动探访。

你负责交素材、说重点、检查效果；AI按主Skill组织流程，并按需调用口误清理、字幕、声音处理等技能。Skill是工作方法，不是剪辑软件，也不包含作者的账号、会员或私人素材。

## 一、第一次准备：账号、编辑器、Skill、连接

### 1. 准备自己的账号与桌面端

在电脑准备能运行Codex的桌面端，登录自己的ChatGPT账号。仅有一个普通网页聊天窗口时，先完成桌面端和编辑器的连接。可用模型与额度以自己的账号为准。

### 2. 选择一个剪辑器，不必两个都装

- **ChatCut路线**：安装ChatCut桌面版并登录；本机安装并登录Codex后，在工程左侧AI面板的Agent选择中选Codex CLI。你可以直接在这里下指令，看同一个窗口里的预览与时间线。
- **CapCut路线**：安装并登录CapCut；在Codex里按CapCut官方入口连接插件。让AI检查当前连接及工程保存位置。云端工程与本机草稿不同，需要本机交付时明确说出来；国内剪映不要直接当成CapCut使用。

下载安装、扫码登录、系统权限按提示完成；不需要自己编写代码。每人使用自己的账号与素材。Codex推理使用对应账号额度；AI配音、生成音乐或视频等可能另需服务积分或会员，先看报价再决定。

### 3. 安装作者提供的完整Skill包

使用作者正式提供的技能包，保留SKILL.md和配套文件的完整结构；本指南不能代替技能包。把压缩包或文件夹交给Codex，或提供本机可访问的位置，然后发：

> 请安装 Autocut，保留完整技能目录，已有同名技能时先比较版本。

如果要在ChatCut的“我的技能”菜单中使用，需要作者提供的对应ChatCut版本或分享入口；它与Codex本机技能是不同位置。不要因为登录同一个ChatGPT账号，就假定技能和聊天记录会自动出现。

### 4. 做一次连接核对

选中 Autocut 后发「开始」。它会引导你交素材或指定现有工程。手边没有素材时可以说「模拟」，用示例体验到审核和导出说明。只有明确要求用真实素材开始实际剪辑，才会切换到真实执行。

## 二、每次开工：选工具、交素材、说重点

### 1. 提交本次素材

- 本次视频的素材放一个文件夹即可；原片、补充空镜、参考视频可简单命名。
- **ChatCut**：把文件或文件夹导入／拖进媒体池，再在AI面板说需求。
- **CapCut**：按AI提示导入或上传本次素材；已有字幕或成片一并提供，避免重复识别。
- 可以提供本机路径、能看出位置和素材范围的 Finder 截图，或指定当前工程。外接硬盘保持连接。Autocut 会在开剪前核对素材是否可读。
- 参考视频、产品名称、价格、数量、联系方式等一次给清；不确定的数据标注“待确认”。

### 2. 看一张预填的剪辑前确认卡

收到素材和位置后，Autocut 会先给你一张「剪辑前确认卡」。文件路径、Finder 截图或已指定的工程都可以。你说过的内容会预填，缺项会标出来。已经给足要求并说开剪时，卡片作为本次回执，核对软件和模型后即可开工。

| 选项 | 怎么选 |
| --- | --- |
| 素材与位置 | 核对文件范围、文件夹或工程名 |
| 编辑器 | ChatCut 或 CapCut，注明是否已打开 |
| 模型 | 显示提供方、具体模型和推理强度，无法核实的会标出来 |
| 类型 | A人物口播／B商业IP／C产品广告／D工厂宣传／E人物＋电脑／F活动探访，可混选 |
| 档位与规格 | 人物口播选择下列三档之一。其他类型说明剪辑和包装范围。带上目标时长与画幅 |
| 语言 | 素材里说什么语言？成片字幕和配音各要什么语言？例如中文原声、英文字幕、保留原声 |
| 重点 | 给谁看，最想说清什么？一句话 |
| 交付 | 可编辑工程的保存位置，是否需要导出 |
| 其他要求 | 默认无，有需要补一句 |

提供方和模型按你已选的设置、已保存的偏好或当前可用的智能体填写。推理强度未指定时，按所选运行环境可用的最高档处理。如果当前工具无法设置或核实，Autocut 会注明。更换提供方会先和你确认。

首次剪人物口播时，确认卡会用三句话帮你选档。MG 指动画字卡或简单的动态图形。

| 档位 | 适合什么需求 |
| --- | --- |
| **粗剪白版** | 剪掉口误、重说和多余停顿，把口播剪顺。字幕和其他处理按你明确提出的要求加。 |
| **粗剪完整版** | 在切剪基础上按确认加字幕、重点字、少量音效和轻量 MG，交一个可编辑草稿。 |
| **直出（最终完整版）** | 做齐字幕、音效、配乐、必要 MG 和基础调色，交一个可编辑工程和检查过的成片。 |

详细标准见[《Autocut 章程》](../skills/autocut/references/charter.md)。

可以直接复制：

> 使用 ChatCut。素材在［文件夹或当前工程］。人物口播，粗剪完整版，约90秒，竖屏。素材是中文口播，保留原声，字幕中文在上、英文在下。重点是［一句话］。保存一个可编辑工程，我自己导出。其他要求无。

工厂完整版可以这样说：

> 使用 CapCut。D工厂宣传，完整版，约60秒，发 TikTok 和 Facebook。素材为中文原声，成片配英文字幕。让海外买家看懂工艺与产品。保留必要原声，配合适的 BGM，人声嘈杂处轻降噪，标题适合海外短视频。其他要求［无或补一句］。保存一个可编辑工程，完成后告诉我在哪里检查。

拿不准时说：

> 素材在这个文件夹。给我一张预填的剪辑前确认卡，我补缺项。

### 3. 回一句，Autocut 核对后开剪

> 字幕改成纯英文，其他要求无。ChatCut 已打开，可以开始。

没要改的也可以直接回复「已打开」或「开始」。Autocut 会核对所选编辑器是否实际打开并可操作，沿用已确认的信息。若连接有问题，只告诉你需要处理哪一步。核对完成后直接开始，按需调用子技能，随工程推进更新进度。

进度通常是：素材 → 识别选段 → 粗剪 → 字幕／包装 → 核心检查 → 待你审核。原生编辑器或可打开的工程用于看画面；进度卡只显示阶段、耗时和卡点，不等于剪辑画面直播。各工具能显示的界面以实际连接为准。

如果想提前看方向，开工时加一句：“先给我看粗剪结构和一处字幕样式，确认后再包装。”否则默认边做边看，不在每个阶段等待人工批准。

## 三、检查与修改：时间点＋一句话

你随时可以指出问题，不用重填需求卡，也不用写专业术语。

> 00:08–00:12，删掉重复起句，只留后面说得流畅的一遍；其他不变。

> 00:23附近，英文按语义分两行，中文位置不变，不要超出画面。

> 00:00–00:02，开场两下敲击想再清楚一点，音尾给第一句留空间。

> 先停一下，我要整理修改意见。不要继续向工程写入改动。

如果你已手动调整，先说明：“我刚改了工程，请读取最新版本后再继续，不要覆盖我的修改。”

AI应区分“已收到”“正在修改”“已应用”“待检查”。删段后时间码会变化，继续反馈时以最新工程为准；有歧义可附截图、选中片段或台词。修改后重点看该处前后几秒及受影响字幕，不必反复重做全片。

### 最后看四件事

1. **话顺**：没有明显拖音、重说，句子完整，接点自然。
2. **字全**：语言顺序正确，长句不越界，字幕不重叠。
3. **声清**：用实际混音听开场与重点字。开场音效听得见，重点提示音对上字的出现时间，人声清楚，配乐让位于台词。
4. **事实准**：名称、价格、数量、单位、日期和联系方式无误。

选择粗剪并打算自己导出，可以这样收尾。

> 这版通过。保存这个最终可编辑工程，告诉我名称和打开位置；不要另建版本，不导出视频，我检查后自己导出。

选择直出时，Autocut 会按确认导出，并检查导出文件的画面、声音和字幕。其他档想要成片可以另外指定画幅、分辨率和格式。发布到社交平台须另行明确要求。

### 试过两三次，把喜好变成下次的起点

有配乐或音效的任务交付后，可以回一句「开场两下敲击听得清，之后这个系列沿用」「这首底乐偏紧，下次试轻一点」。Autocut 会按客户或系列区分本次试用与已确认偏好。两三次后归纳重复出现的选择，下次预填，随时可覆盖。

## 常见卡点：直接这样问

- **找不到Skill**：“请检查autocut是否已安装、能否读取完整说明；不要重新装一堆无关工具。”
- **素材或工程读不到**：“保留当前需求，告诉我缺哪个文件或哪一步连接；不要反复重试。”
- **需要收费**：“先告诉我哪个功能收费、费用和替代方案，确认前不要执行付费生成。”
- **听不清价格或名字**：“把不确定的那一句单独标给我确认，其他部分继续做，不要猜。”

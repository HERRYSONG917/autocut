# 验证范围

Autocut 0.3.0，2026-11-23。

## 已完成检查

- 官方skill-creator验证器检查主入口、名称与YAML；显示信息与默认调用提示检查通过。
- 文档相对链接能够定位对应文件，三个 Python 辅助脚本能编译并显示使用帮助。
- 原版七步流程图与更新后的三页图文手册均包含在技能目录及压缩包内。手册经渲染核对，文字可选。
- 已逐条核对新规则与两条 ChatCut 实剪反馈，另检查以下流程场景。规则复查期间没有重新剪辑测试素材。

  - 一句「开始」先引导交素材；收到路径后立即给预填确认卡，补项和开工可在一句话里完成。
  - 推理强度不可读且未设为硬条件时，标记未核实并继续用原入口。
  - 模拟中收到实际路径仍保持模拟。用户明确要求用原片真剪时复用确认卡，核对实际编辑器后才执行。
  - 首次口播按三档出卡。白版只加用户点名的音效或 MG，依照交付约定保留工程。
  - 外语对谈升级直出时复用工程，分开核对原声与字幕，按实际混音验收。存疑事实标时间，确认后再放进成片。
  - 返修优先读取人工修改后的版本。首用建私有喜好库，待反馈选项与已认可偏好分开记录。

下面的脚本行为在 0.1.0 已用合成样片检查，0.3.0 沿用同一实现。

- 以临时生成的小视频验证素材登记、ffprobe元数据读取及第二次扫描缓存复用。
- 以有声/无声小视频验证FFmpeg场景候选扫描，并在已知静音区间检测到混音静区。
- 参考扫描拒绝覆盖输入、无效采样率及超时任务；测试前后原始样片哈希相同。
- 合法SRT检查通过，重叠SRT返回错误；脚本只检查文本与时码。
- 公开文本与代码未发现已知私人路径、账号标识或客户样片数据；图文手册单独检查。

这些检查使用合成媒体，不访问客户素材，不调用付费云服务。打包时还检查压缩包内容与源文件一致，排除缓存和构建过程文件。

本包是可复用的流程指令与辅助工具，不是经过全部设备、地区和账号验证的成品剪辑器。脚本检查不能替代编辑器中的实际观感审核。

## 使用者首次试用

用自己的短样片检查：能否读取当前工程和素材；能否完成一次小剪切/字幕修改；能否保存并从约定位置打开；修改时是否保留人工调整。确认这一条链路后再处理完整商业任务。

CapCut桌面草稿与云端工程的连通性、ChatCut不同版本的原生特效及自动化接口，都取决于当前连接。没有针对所有剪辑器和账号进行端到端回归测试，不承诺一定时间完成或完全无人介入。

收费生成、语音克隆、客户数据上传和对外发布不属于本包的结构验证，不会为测试而自动调用。

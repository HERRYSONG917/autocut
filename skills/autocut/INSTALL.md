# 安装与开始

Autocut v0.3.0 · 2026-11-23

这个文件夹就是技能本体。必须保留`SKILL.md`、`references/`、`agents/`及其他配套文件，不能只复制主说明。

## 不写代码的方式

1. 把完整安装 ZIP 或解压后的 `autocut` 文件夹交给 Codex，发送下面这句话。

   > 请安装 Autocut。保留完整技能目录，已有同名技能时先比较版本。

2. 安装后选择 **Autocut**。也可在新对话发「使用 $autocut 开始」。未显示时按宿主提示刷新或重启。
3. 在 Autocut 对话中发「开始」「怎么做」或「我想开始剪辑」。根据引导交素材和位置，发 Finder 截图，或指定已打开的工程。手边没有素材时回复「模拟」，用示例试一遍。发出真实剪辑要求后才切换到实际执行。
4. 查看预填的「剪辑前确认卡」。卡片列出编辑器、模型提供方、具体模型、推理强度、剪辑档位、素材原声语言、成片字幕或配音语言，以及交付方式。「其他要求」默认无。推理强度未指定时按所选环境可用的最高档处理，无法设置或核实时会注明。
5. 补充或修改时一起回一句，例如「字幕改成纯英文，ChatCut 已打开，可以开始」。Autocut 核对编辑器确实可用后沿用已确认的信息，直接进入方案和剪辑。更换模型提供方会先与你确认。

开始前，按提示连接自己的 ChatCut 或 CapCut。想先看全流程，可以打开[七步流程图](assets/guide/flow.png)和[新手图文指南](assets/guide/quickstart.pdf)。

### 口播三档与反馈

| 档位 | 怎么交付 |
| --- | --- |
| **粗剪白版** | 剪顺口播，明确要求的字幕或其他项按确认补。 |
| **粗剪完整版** | 按确认加字幕、重点字、少量音效和轻量 MG（如动画字卡），交一个可编辑草稿。 |
| **直出（最终完整版）** | 做齐字幕、音效、配乐、必要 MG 和基础调色，交可编辑工程和检查过的成片。 |

修改时给时间点和一句话，例如「00:00–00:02，开头敲击再清楚一点，第一句也要听得清」。有声音包装就听实际混音。暂停时说「先停住」，人工调整后说「先读最新工程再继续」。试过两三次后，可让 Autocut 归纳你已经确认的偏好，在同系列下次开工时带入。

## 安装位置与更新

让当前宿主检测它实际使用的技能目录。不同Codex版本/环境可能使用`~/.agents/skills`或`$CODEX_HOME/skills`等位置，不要同时复制多份同名技能造成歧义。若手动安装，完整目录应为`实际技能目录/autocut/SKILL.md`。

更新时只替换该技能包自己的文件，保留用户本地偏好、媒体和工程；先确认同名旧技能是否有个人改动。本包不是自动更新器。

ChatCut桌面AI面板选择Codex CLI时，应检查该进程可发现的技能目录。安装为Codex技能不等于已注册ChatCut“我的技能”；原生菜单保存需要按ChatCut官方流程单独完成。

## 连接与依赖

- CapCut：[官方连接入口](https://www.capcut.com/tools/capcut-x-codex)。云工程与桌面草稿不同，明确希望交付的位置。
- ChatCut：[桌面安装](https://chatcut.io/desktop)、[桌面Agent说明](https://chatcut.io/docs/desktop-app)。素材导入媒体池后再开始，外接盘保持连接。
- 本地脚本是可选辅助；Python 3.9+，分析参考片需要已有FFmpeg，元数据探测需要ffprobe。没有该需求不安装。

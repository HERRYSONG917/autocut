# 效率、检查与交付

## 时间目标

普通 1–2 分钟片：粗剪白版以 20–30 分钟为计划目标，粗剪完整版按增项评估，直出以 30–40 分钟为计划目标。计入导入或上传、审核和导出等待，遇到长素材或服务排队按实际更新时间。

| 工作 | 普通任务预算；可交叉，不要求全部耗满 |
| --- | --- |
| 需求与素材定位 | 2–3分钟 |
| 识别与选段准备 | 4–6分钟，已有稿跳过重复识别 |
| 核心剪辑与包装 | 粗剪约10–15分钟；完整版约18–24分钟 |
| 核心检查 | 约3–4分钟，只检查高风险与修改处 |
| 保存与交接 | 约2–3分钟 |

把时间花在句子接口与核心表达。不要每片重装模型、研究新框架、做新看板、重复上传或反复导出预览。读取相关参考，复用文字稿、媒体ID、术语、选段和切点映射。用户只改一句时只重做关联部分。

遇到明显超时风险简短告知当前卡点与可行处理，不静默拖延；没有证据不要归咎于电脑GPU或网络。失败只做一次有依据的重试，先查既有任务状态，避免重复费用和版本。

## 快速但必要的检查

- 话顺：不完整重说已处理，明显无意义拖音去掉，剪口不吞字、不改原意。
- 字全：关键事实、语言、时码和同步；检查短句、最长句和双行句的实际显示。发现问题再扩展同类项。
- 声清：按[章程验收](charter.md#最终检查与返修)。用实际混音检查开场声能辨认、每处黄字同步提示、对话清楚且配乐贴合语气。
- 画面与包装：请求的时长/画幅、开头、适当标题与必要片尾；粗剪不强加完整版项目。
- 工程：保存到约定位置，可打开，素材引用完整。

用户明确说调色只做基础、由他检查时照办，不额外反复检查调色。未能检查的项目写清楚，不把工具调用成功等同于观感通过。

## 一个最终工程

默认在同一可编辑主工程持续修改。直出默认交一份经过检查的成片和可编辑工程，其他档默认交工程，当前交付约定优先。工具支持的非破坏历史可以保留。文件名简洁，例“品牌工厂｜海外宣传｜最终版”。

用户手动完成的版本是最新依据，读取后再追加。桌面草稿交付需实际核对App草稿入口，不把云端链接冒充本机记录。工具不支持指定位置时明确实际位置与差异，不能报完成了未做到的部分。

旧工程、重复上传和预览成片只有在用户授权范围内清理，先检查最终工程是否仍引用；不自动删除原片、共享素材和必需依赖。新任务另建自己的工程，不覆盖旧项目。

交接时说明完成内容、工程或成片位置、待核对项。直出后检查导出文件本身。交付涉及配乐或音效时，回收用户对本次声音的反馈，再按章程更新喜好库。只有另有明确要求才处理发布、投放或发送。

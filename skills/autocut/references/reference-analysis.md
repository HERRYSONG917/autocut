# 轻量参考片分析

目的：提炼可复用的结构、节奏、字幕、音效和结尾方法，不复制客户私人信息，也不是训练新模型。已有品牌规范就先复用；用户只要普通剪辑时，不额外开展长篇研究。

## 组合分析，而非只看三张图

1. 先读元数据与现有文字稿，判断时长、画幅、语种、源片类型。
2. 代码扫描切点候选、镜头长度分布、混音静区或音量变化；保存小型JSON与候选时间点，不复制整段视频。
3. 用带时间码的实际台词分析钩子、信息顺序、重复与情绪转折；ASR文本不能证实所有口头拖音已经消失。
4. 根据候选切点、最长字幕、图文/人物切换与结尾抽取低分辨率关键帧。不是每次固定只看开头/中段/结尾，也不用全片逐帧上传。
5. 关键剪口、音乐压声或疑似拖音处检查短音画窗口；只靠图像不能判断声音，音量数字也不能证明词句清楚。
6. 输出可执行规范：适合哪类片、结构、节奏区间、字幕样式/安全区、SFX用途、BGM关系、片尾和禁用做法，区分“观察到”和“推测”。

`analyze_reference.py`使用现有FFmpeg，将视频缩到256宽、默认每秒6帧做场景候选扫描；混音以-35dB、至少0.30秒检测静区。它仍需解码输入，不能承诺零算力；不会保存抽帧或渲染MP4。每文件默认超时120秒，可调整；没必要就不运行。

切点候选可能把转场、字幕变化、相机移动误认为换镜，也会漏掉相似机位跳切；每秒6帧限制时间精度。混音静区不是人声VAD，BGM能遮住人声停顿。脚本不做逐词识别、OCR、语义选择或自动合格判断。

默认只保存相对名称和小型测量。客户私有路径、脸部截图、脚本、原片及品牌资产不进入公共Skill。品牌偏好用用户自己的[品牌配置模板](../assets/brand-profile.example.md)单独维护。

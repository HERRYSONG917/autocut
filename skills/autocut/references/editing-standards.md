# 剪辑、包装与声音

## 类型与结构

| 类型 | 结构建议；按实际素材取舍 |
| --- | --- |
| A人物口播 | 开头核心问题/观点 → 清楚的解释 → 完整收束 |
| B商业IP | 人的观点与可信经历为主；金句强调，不改造成夸张广告 |
| C产品/投放广告 | 需求或痛点 → 产品演示/证据 → 清楚行动引导；不编性能和价格 |
| D工厂宣传 | 工厂/产品钩子 → 生产步骤/材质 → 质检/细节 → 产品与联系引导；口播与空镜互补 |
| E人物＋电脑 | 讲到哪展示哪，必要时切演示或画中画，屏幕文字需可读 |
| F活动探访 | 先交代现场和价值 → 重点人物/细节 → 总结；避免无意义流水账 |

一分钟工厂片可按约3秒开头、10秒定位、30秒生产与证明、10秒产品、5秒收尾规划；这是参考，不强行填满时间。优先用证据画面说明台词，保留必要机器环境声，不能BGM盖住介绍。用户明确时长优先。

## 剪辑档位与范围

人物口播按[章程](charter.md)确认三档和包装范围。其他类型按确认卡选择必要的标题、空镜、转场和收尾。额外美颜、复杂调色、特殊动画或配音仅按本轮需求执行。

调色从基本曝光、白平衡与镜头一致性入手；若工具有智能调色，使用本轮要求的档位，不把“三层/三档”解释为通用滤镜参数。一次基础处理即可，不耗时追求大片风格；用户说自己检查时不额外反复调色。

## 每一句的接口

- 同时参考逐词文字稿、实际声音和画面。ASR可能完全不写“呃”，静音检测也不会把有声拖音识别为静音。
- 删除没有意义的“呃/额”、失败起句、重复讲法及不必要拖长。后面重说更顺，则保留流畅完整的一遍。
- 录音“尽可能降低他们的成本……出海成本”可用原声重组为“尽可能降低他们的出海成本”，删前一个“成本”，接后面的“出海成本”。核听接点，不能删成断句、吞字或篡改意思。
- 保护否定、条件、因果、数字与单位。情绪停顿、自然换气、有效强调不机械删除。
- 剪到音素/词尾安全处，必要时使用短交叉淡化避免爆点。伴随手势也看连续性，可用现有空镜覆盖明显跳切。
- 只在合适的片段轻微提速；不为了时长整片强行加速。剪切、提速之后用源时间映射更新字幕与音效位置。

## 人声、BGM与音效

人声优先。音量偏低时适度提升并控制峰值；噪杂处有针对性地轻降噪或人声增强。听不清先做一次合适的清晰度处理，再核听；不要给机器噪声反复叠效果，也不能把听不懂的词猜成产品事实。

按[章程的剪辑与包装](charter.md#剪辑与包装)选择配乐并混音。严肃独白可试克制钢琴；像朋友聊天的实谈可试温暖拨弦与轻节拍，语气以原片为准。全段对白通常沿用一条无歌词配乐，讲话时压低；对白与空镜交替时可按叙事分段或用关键帧抬空镜底乐。必要时错开第一句、进场重音和音乐的起点。用于广告的音乐与字体须符合相应用途的授权；本轮明确限收藏时就从收藏选。

试听开场和任一黄字重点处的实际混音，确认进场声可辨，提示音与黄字同起，第一句和关键字仍能听清。开场重音可随原声音量略抬，必要时调整音色、进入点和音乐音量。在试听受限时记录确认了哪些实际音轨或响度，听感留给用户复核。

使用用户提供并确认的品牌片尾时复用其真实素材，不把某位创作者的专属片尾复制给所有人。

## 系列问答的精简包装（按已确认偏好使用）

- 音效随用户约定和实际重点分配。开场需要有可听的主重音，转折和重点句用轻提示；按章程分别验收。
- 常规字幕用白字。每条挑两三处能独立表达观点的重点句，用黄色粗体强调，并在起点同步提示音。加粗后按实际画面宽度复核。
- 问题讲完且转入回答处有余量时，可以弹出一张简短透明 MG 问题卡。人物上方有留白时可放上方，镜头、手势或字幕位置变化时移到其他安全区域。回放检查整个动画的入场、停留、退场与字幕和人物的关系。
- 只微调明显拖音、重说和多余停顿。听一遍提问到回答的接点，保留接话、换气和强调的自然节奏。

用户要求自定义 MG 时，按本次参考提取配色、字重、布局与动效节奏。暖橙、暖黄和深色可用于暖色极简设计，韩式简洁排版与非线性缓动按具体参考使用。风格只记入对应项目；用户明确要复用时再收进个人或系列喜好。

# 剪辑前确认卡

收到可识别的素材及位置后，下一条先给预填卡，目标是 30–60 秒填完。附件、可读截图或已打开工程都能作为素材入口。截图里的文件名和路径可以先带入，实际能否访问另行核对。没看到的时长、画面和文件范围写待核对。

先读[章程的开工与选档](charter.md#开工与选档)。首次选择人物口播档位时，在卡里各用一句话解释三档；用户已明确时直接预填。

| 项目 | 预填内容 |
| --- | --- |
| 素材及位置 | 文件／选择范围、文件夹或当前工程 |
| 剪辑软件 | ChatCut / CapCut；有指定就沿用，未指定就推荐或给两个选项 |
| 执行模型 | 提供方、确切型号、推理强度；注明待核对的值 |
| 类型与重点 | 口播／商业IP／产品广告／工厂／人物＋电脑／活动探访；一句话写给谁看、要讲清什么 |
| 剪辑规格 | 人物口播的三档之一、时长与画幅。只说「粗剪」时按本轮要求推荐白版或粗剪完整版；用户点名的增减项单独带入，不自动升档 |
| 原声与成片语言 | 原片说什么语言、保留原声还是配音、字幕用什么语言和布局。用户纠正源语言时，沿用已确认的交付语言，兼有歧义时只补问这一项 |
| 其他要求 | 默认「无」；用户只需补一句，如只用收藏、保留某句或先看粗剪 |
| 交付 | 一个可编辑工程。直出默认另交成片；「我自己导出」等明确要求优先。写清约定位置 |

从本轮要求、已确认的偏好和素材信息预填。明确把假设标为建议（例如建议竖屏）。用户只用说「按卡开始，ChatCut 已打开」，或直接改一两项；确认、修改和软件打开状态可以放在同一句。已给足要求且明确开剪时，展示卡片作为开工回执，继续检查和执行。已确认的卡不重发，续做和修订只处理新变化。

先给卡再开展方案或深入分析。给卡后自行核对素材访问、[编辑器和实际执行模型](backends.md#开工前核对)。只有确实需要用户开软件、选择一个可用模型或提供缺项才停下来说明下一步。模拟使用同一张卡并标注当次状态。

例如用户说「用 ChatCut 做 90 秒白版，只补片头轻音效和一个标题动效。阿语原声，中文字幕」时，按白版加这三项明确增项，交可编辑工程。用户已提供重点并说「ChatCut 已打开，按卡开始」，核对连接后即可制作。

如所选编辑器需要把外接盘或本机素材上传云端，明确这是云上传，并沿用本次已有授权。

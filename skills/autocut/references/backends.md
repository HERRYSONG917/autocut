# 执行工具与依赖

## 一次任务，一个主要编辑器

尊重用户选择与当前工程。未指定时：偏自动选段、文字稿操作且ChatCut已连接，可优先该路线；需要CapCut原生收藏/模板或既有CapCut工程，则沿用CapCut。依据真实能力推荐，不宣称某工具一定省多少token。

## 开工前核对

- 核对所选编辑器已打开或已进入所选网页编辑界面，当前连接能访问素材和目标工程，并支持实际写入与约定交付。用户已说打开，不再请他重复打开；能够自查就核对连接和工程。有明确卡点时只说下一项需要的操作。
- 确认需要执行剪辑决策的 Agent/模型：提供方、确切型号、推理强度。先带入当前指令，其次是用户已存默认，缺省可沿用当前已连接且同一授权范围内的 Agent。没有指定强度时，使用该入口、具体型号和会话实际支持的最高推理档；已选定的速度档、账号与服务按用户要求沿用。
- 核对真正运行的入口。Codex 在对话里决定剪法并通过编辑器工具操作时，核对 Codex 这一侧；在 ChatCut 内委派剪辑给它的 Agent 时，核对 ChatCut 界面实际所选的 Agent 和模型。只有宿主明确支持设置和回读时才改档和报告已生效。如果当前入口看不到或无法改变型号、强度，直接标「无法核实」或「此入口不可切换」。
- 用户把某个提供方、型号或强度设为硬条件时，无法满足则先停该模型的执行，只提示如何选定已授权的对应入口。只有普通偏好或未指定时，当前值不可见也可沿用当前入口，标注未核实即可继续。不擅自开通新账户或切换到另一提供方、计费入口或编辑器。转录、渲染等由实际工具承担，按各自入口核对。

## CapCut

使用已安装官方插件的当前工具；如可用，按任务读取其`video-editing`、`web-collaborative-editing`或`capcut-stdraft-builder`等技能。云素材上传仅在该路线确需且已获授权时进行。使用已有媒体ID和同一草稿，超时先查询状态，避免重复提交。

官方连接入口：[CapCut × Codex](https://www.capcut.com/tools/capcut-x-codex)。插件的安装与授权跟随该入口当前说明，不执行包里自造的安装脚本。

云端草稿、网页协同工程、本机草稿不是同一个交付位置。需要桌面草稿时，先确认当前版本支持的打开/下载/同步方式；用桌面App实际看到的记录验证。不能只返回网页链接却声称已在本机草稿箱。

官方工具不能完成本次要求时，明确能力缺口；在已有授权范围内使用桌面操作或本地辅助。不要从不公开的草稿结构猜测写入，不能把渲染MP4当成可编辑时间线替代品。

## ChatCut

发现当前可用的ChatCut工具，连接到用户实际打开的本机或网页项目；本机和网页路线的媒体可访问性不同。读目标项目后再编辑，操作后核对最新状态。用户素材文件未导入时，按支持的导入操作处理；文字路径不等于已导入。

按任务使用可用的官方技能，例如口播清理、转录/字幕、声音隔离、动效等；具体名称和接口以安装版本为准。缺少某个技能并不意味着安装了本包就自动拥有该能力。不要批量读取全部技能，也不要静默切换到付费生成路线。

桌面左侧选择Codex CLI时，Codex的推理用量由对应登录方式/套餐决定；ChatCut托管生成等可能另计积分。不得承诺绑定ChatGPT后所有功能免费。原生ChatCut“我的技能”和Codex本机Skill属于不同位置，本ZIP不会自动注册到“我的技能”。若用户另要原生保存，使用当前官方流程并验证。

官方资料：[桌面与本地Agent](https://chatcut.io/docs/desktop-app)、[技能说明](https://chatcut.io/docs/skills-overview)、[积分规则](https://chatcut.io/docs/credits-policy)。

## 本地辅助与失败恢复

本包只有只读登记、参考扫描、SRT检查脚本，不包含FFmpeg、ASR模型、剪辑器或完整离线剪辑引擎。Python脚本使用标准库；需要的FFmpeg/ffprobe应先探测已有路径，未安装时才解释最小依赖。官方编辑器已能完成就不搭建新代码流水线。

一次失败先用证据判断原因；只做一次有理由的重试。超时不等于未执行，先查询，防止重复任务和重复费用。仍失败时按用户预先授权转入兼容备用路线，否则只问该项迁移/上传/费用，不重新问整张需求卡。保持原要求及现有结果。

本版本未在所有设备、账户、地区及两个编辑器上完成端到端测试；不能仅凭工具返回成功宣称剪辑质量通过。

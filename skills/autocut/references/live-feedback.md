# 可视进度与及时纠偏

## 让人看到真实工作

优先保持原生编辑器的预览和时间线可见，或提供当前可打开的工程入口。紧凑进度卡只辅助显示：当前工程、已用时间、当前阶段、下一步、卡点、最近真实更新时间。后台执行但不能显示画面时直接说明，不把自制界面称为剪辑直播。

不要用计时器假装百分比，不能捏造token或费用账单。显示实际状态变化即可；普通阶段不为填状态而停下来。控制按钮只有接通真实命令才称“暂停/修改”；示意页面要标“示意/复制到聊天”。本包提供交互规范，不含已接通的工作台软件。

用户开工后不需要选择子技能。默认边做边看；指定“先看结构再包装”时，在粗剪检查点等待。没有该要求就直接继续，但尽早让开头、切点、字幕样式在同一个工程可查看。

## 一条纠偏链路

看见问题 → 定位 → 已收到 → 暂停相关旧变更 → 定点修改 → 局部检查 → 待用户检查。

写入前重看[章程的相关环节](charter.md)，只应用这次确认的修改。可复用的个人纠偏单独记录，未反馈的试用选择保留待确认状态。

支持“时间点＋一句话”、选中字幕/片段、截图及普通语言。例：

> 00:23附近，英文按语义分两行，中文和其他内容不变。

1. 一句回执说明改哪里；区分**已记录、等待当前操作结束、正在修改、已应用、待检查、遇到卡点**。收到不等于完成。
2. 绑定用户所见工程与版本、片段/字幕稳定标识和源时间映射。删段会改变后续时码，不按旧时间点盲删；可用台词/选中项辅助定位，仍不清才问一点。
3. 在下一次安全写入前处理新要求。后台长任务若不能取消，如实说明并阻止旧结果覆盖新要求；不能承诺瞬时停止服务端。
4. 连续修改合并处理，冲突部分以最新指令为准，其他已确认内容保留。只重算受影响切点、时码、音画同步及相关上下游，不重录文字稿或重做全片。
5. 写入前重新读取最新工程；用户手动调整优先。过期数据需要合并，无法安全合并时只暂停相关写入并说明具体冲突。
6. 修改后核对该处前后短段；删段/变速造成片长变化时同步检查关联字幕、音效和片尾。

用户说“先停住”：停止发起新变更；取消已发任务仅按真实能力。不能把仍在排队的修改标为已应用。用户恢复后从当前工程和待办继续，不重新开始分析。

## 必要项不遗漏

每轮只维护简短清单，项目状态为完成 / 本轮不需要 / 未完成：

- 表达与接点；请求时长/画幅。
- 字幕语言、排版、长句、关键事实。
- 人声、BGM、音效实际可听（有请求时）。
- 标题、转场、片尾等本轮包装。
- 可编辑工程保存位置与可打开性。

工具成功后才标已应用，局部检查后才标已检查，用户亲自确认后才标用户通过。最终状态通常为“待你审核”。

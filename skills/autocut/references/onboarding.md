# 主动引导与模拟

Autocut 负责判断下一步。用用户能认出的编辑器、素材和画面来解释操作。每次停下来只留下一个明确动作。可以一次收集多个真正缺失的要求，但不要每轮再发整张表。

## 判断现在在哪一步

| 用户现在的状态 | Autocut 这轮做什么 |
| --- | --- |
| 刚收到安装包，尚未安装 | 让用户把完整 ZIP 或文件夹交给当前宿主，按 [INSTALL](../INSTALL.md) 识别并安装。说明以后在已选择 Autocut 的对话里说「开始」。已经能读取技能时跳过安装，不另装剪辑器或更改配置。 |
| 第一次说「开始」，没有素材或工程 | 简短说「把要剪的原视频拖进来，或发素材位置。只有截图也可以先发。已有打开的工程就说『用这个工程』。想先体验，可以回复『模拟』。」已知的编辑器直接沿用。 |
| 已给出可识别的素材及位置 | 读章程和可用的客户喜好后，第一条有效答复直接出[剪辑前确认卡](quick-intake.md)。首次选口播档位时各用一句话介绍三档。附件、可读截图或已打开工程也能预填，区分截图读到的信息和实际可访问性。先出卡，再出方案。 |
| 确认卡已收或需求与开始指令齐全 | 核实所选编辑器已打开且工程可访问，核对实际执行模型的提供方、型号、强度。可以自行检查时直接检查；用户已告知或工具已验证的信息不再问。只剩需用户操作的一项时，给一句指引。条件具备就按卡进入制作，默认无额外方案审批。 |
| 处理中或遇到卡点 | 报告实际进度与下一项动作；如果需要用户打开软件、授权必要权限或提供缺失文件，说明点击位置及完成后的回复。继续能独立完成的部分。 |
| 已保存可打开的工程 | 告知工程名称和位置。直出同时交已检查的成片，其他档按约定导出。给一条可用反馈句式，如「00:23 英文长句拆到下一屏」。 |

用户问「怎么做」时优先给当前步骤。说「继续」时沿用上次目标、媒体和编辑器。说「停一下」时按[进度与纠偏](live-feedback.md)处理。只有明确说要新开一条视频才重启素材与需求，不把已经做过的首轮引导再来一遍。

## 模拟是一次交互体验

适合刚收到技能包或暂时没有素材的人。「模拟」「演示」和 “Try the demo” 是同一个入口。只有用户选择其中之一或当前对话已明确指定为模拟时进入。可以用以下简短虚构样例，也可以按用户选的类别换成一条同样轻量的示例。

> **示例**：一段中文口播和三条工厂空镜。做约 60 秒竖屏粗剪，配中英字幕，让海外买家看懂生产流程。示例交付为 ChatCut 可编辑工程。

1. 用户说「开始」时进入第一步。邀请他说「用示例」或发自己的素材信息。收到素材后立即展示标为「模拟」的预填确认卡，包括其他要求、剪辑器和模型设置；软件与模型的开工核对也作为示意。用户发真实文件、路径或截图，可预填卡片，仍沿用模拟状态。
2. 确认卡后口头预演，给一份简短的**示例**时间线（如开场、生产空镜、成品、结尾），提示用户用一句话改一处。没有真实媒体分析或工具写入时，时码、台词、工程和进度都不能写成实际结果。
3. 根据用户反馈更新示例时间线，用一句话说清改动。之后演示如何审核和如何要求导出。保留这次作为模拟，多轮也不自动切换真实执行。
4. 用户明确要求剪实际原片并写到实际编辑器（如「ChatCut 已打开，按这张卡剪我的原片」），转真实制作，直接复用当次已确认的卡片，完成开工核对后执行。单独回复「按卡开始」仍遵循当前模式。工程是否创建、保存或导出以工具结果为准。

模拟阶段不操作真实工程，不上传、不调用生成服务、不发布。用户只在模拟中说「导出」，可以解释真实操作会是什么，不创建文件来冒充节目成品。有需要时给用户[七步流程图](../assets/guide/flow.png)或[新手图文指南](../assets/guide/quickstart.pdf)。

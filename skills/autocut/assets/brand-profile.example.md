# 我的品牌剪辑偏好

首次接单时为本人建立喜好记录，开工前先读。留空项沿用章程和对应档位。每次以当次要求为准，其次用本系列已确认的偏好。通用流程和验收标准另见[Autocut 章程](../references/charter.md)。

## 通用开工设置

- **编辑器和模型**　可填写常用编辑器、模型提供方、确切型号、推理强度；仅在已经连接且实际支持的入口使用。可单独注明必须使用的选项。

## 系列设置

- **适用系列及识别方式**　系列名、别名、受众、平台，或由我明确指定。
- **标准写法**　填写「中文标准名 / 英文标准名 / 已知旧写法」。同一个人、账号、品牌或系列的字幕、动效、标题、工程名、交付说明统一使用标准名。
- **原声和字幕**　分开记录常见原声、成片字幕语言、配音偏好。可选中文在上、英文在下，各自可编辑且各一行。长句按语义拆成相邻两屏，按画面宽度验收。
- **重点强调**　可选白色常规字幕，挑两三处关键句用黄色粗体。每处黄字起点配一个柔和提示音。
- **音效和节奏**　分别记开场强调声和中段轻提示的音色及力度。开场需在实际混音中辨认清楚。记录希望保留的问答节奏。
- **MG 动效**　记录偏好的用量、颜色和运动风格，白版按本轮明确追加。可选提问结束后显示简短透明问题卡，跟随画面留白避开人脸和字幕。
- **应用到哪个档位**　粗剪白版 / 粗剪完整版 / 直出（最终完整版），按偏好逐项注明。
- **选材与包装**　按严肃独白、轻松对话等场景分别记录 BGM 风格及授权、常用字体、收藏限制、标准片尾和参考片。
- **交付偏好**　桌面草稿 / 网页工程 / 其他。

## 反馈记录

每项记为「已明确」「本次试用」或「待反馈」，注明适用的人、系列和场景。第一次交付后可就实际用过的配乐、音效或 MG 问一个具体问题，反馈后记录保留项或修改项。做过两到三次时，归纳用户重复认可的选择和场景例外。单次指定风格留在本次项目记录。

另存为 `brand-profile.local.md`，仅自己使用。可放在当前项目目录，或者 Codex 配置目录下的 `autocut/` 内供不同剪辑项目读取，也可以直接告诉 Autocut 文件位置。公开分享时使用此空白模板。编辑器支持保存偏好时，可同步用户确认的系列规则和标准写法，写入后读回校对。
